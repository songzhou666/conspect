# 报表板块模式库（22 板块 · 6 族）

> 本文件是 conspect「汇报内容选型」阶段的**唯一选型依据**。
> 板块 = 报表的一个内容单元。选型阶段按 **触发条件** 从本库中挑板块、组成 `_cs-content.md`（报表大纲），
> 再由「生成报表」阶段按板块 → section type 的映射装配。
>
> 字段说明：
> - **必需度**：`必需`／`条件`／`可选`。必需 = 不论数据如何都要出现；条件 = 满足触发条件才出现；可选 = 用户明确要求才出现。
> - **触发条件**：由数据特征或用户诉求判定，满足即自动纳入。
> - **section type**：对应 `conspect_tools/render_engine.py` 支持的板块类型（`kpi_cards`／`section_group`／`chart`／`table`／`conclusion`／`custom`／`prose`）。

## 二、板块规格

### 族 A · 开场 OPEN

#### B01 封面页
- **必需度**：必需
- **触发条件**：无条件
- **内容要素**：报表主标题 · 副标题（一句话结论）· 数据范围（时间区间 / 业务范围）· 数据源摘要（文件数 / 记录数）· 生成日期
- **呈现形态**：整屏居中，主标题最大字号，副标题用次要文字色，底部一行元信息
- **禁忌**：不放任何图表；副标题不得用「数据分析报告」这类空话，须是本期最关键的一句结论

#### B02 执行摘要
- **必需度**：必需
- **触发条件**：无条件
- **内容要素**：3–5 条核心结论，每条一句话，按重要性降序；每条可带一个关键数字
- **呈现形态**：编号列表，字号比正文大一档，一屏读完
- **禁忌**：不超过 5 条；不得出现「详见第 X 节」式的转述；不得与 B15 核心发现重复——摘要只放**结论**，B15 放**结论 + 证据**

#### B03 目录导航
- **必需度**：条件
- **触发条件**：板块总数 > 6
- **内容要素**：章节目录（编号 + 标题 + 一句话导语）+ 各章所在屏次
- **呈现形态**：网格卡片或编号列表
- **禁忌**：板块 ≤6 时省略，避免占用一屏却信息量过低

### 族 B · 指标 METRIC

#### B04 KPI 指标墙
- **必需度**：必需
- **触发条件**：无条件（无可用数值指标时降级为「关键维度概览」）
- **内容要素**：每个指标 = 名称 + 当前值 + 单位 + 同比/环比变化 + 变化方向
- **呈现形态**：卡片网格，每行 ≤4 个，数值字号显著大于标签
- **禁忌**：不放超过 8 个指标；变化方向不得只用颜色区分（须同时用箭头或正负号，保证黑白打印可读）

#### B05 目标达成仪表
- **必需度**：条件
- **触发条件**：数据中存在「目标值 / 预算值 / 计划值」列，或用户明确提出达成率诉求
- **内容要素**：目标名 · 实际值 · 目标值 · 达成率 · 差距
- **呈现形态**：仪表盘或进度条 + 达成率数字
- **禁忌**：没有目标列时不得编造目标值

#### B06 迷你趋势卡
- **必需度**：可选
- **触发条件**：暂不启用——渲染引擎没有「迷你折线（无坐标轴）」组件，
  硬选进来只会在装配阶段留下空洞的缺口。趋势统一由 B07 承载。
  接入 sparkline 组件后，把本条恢复为「用户明确要求看趋势，或存在 ≥6 个时间点」
- **内容要素**：指标名 + 当前值 + 迷你折线
- **呈现形态**：卡片内嵌微型折线（无坐标轴、无图例）
- **禁忌**：迷你折线不得加坐标轴标签，否则与 B07 职能重叠

### 族 C · 分析 ANALYSIS

#### B07 趋势分析
- **必需度**：条件
- **触发条件**：存在时间/日期维度且该维度 ≥5 个不同取值
- **内容要素**：标题 · 时间趋势图 · 1–3 句业务解读（说清「涨在哪、跌在哪、拐点是什么」）
- **呈现形态**：左上角主图位置；数据点 >50 用面积图，≤50 用折线图
- **禁忌**：时间点 <5 时不作趋势判断，改用 B09 对比排名

#### B08 结构构成
- **必需度**：条件
- **触发条件**：存在类别数在 2–10 的分类维度，且数值可加总。
  判定取**最接近构成图可用的那个维度**（最小类别数），不取最大——
  一张表里常有「所在城市」15 类这类不适合构成图的维度，
  但同时也存在「产品类别」4 类，只按最大类别数判定会把构成图整块误排除
- **内容要素**：构成图 + 占比解读 + Top1/Top3 集中度
- **呈现形态**：类别 ≤5 用饼图；6–10 用环形或水平堆叠；多层级用旭日图/树图
- **禁忌**：类别 >10 时改走 B09；不得用饼图承载 10 类以上

#### B09 对比排名
- **必需度**：条件
- **触发条件**：存在分类维度（类别数 ≥3）或需要 TopN 排序
- **内容要素**：排名图 + 领先/落后差距解读
- **呈现形态**：类别 >10 用横向条形；5–10 用柱状；双维度交叉用分组柱
- **禁忌**：类别 ≤5 且强调占比时优先 B08，避免与饼图重复

#### B10 归因分析
- **必需度**：条件
- **触发条件**：存在可分解的贡献结构（子项加总 = 总体），或用户明确问「为什么涨/跌」
- **内容要素**：帕累托图（柱 = 单项值 + 线 = 累计占比）或瀑布图（每步增量）+ 二八结论
- **呈现形态**：与雷达图并排时归入「深度洞察」分区
- **禁忌**：子项无法加总到总体时不得使用瀑布图

#### B11 分布与离群
- **必需度**：条件
- **触发条件**：存在数值列且非重复值 ≥20 个
- **内容要素**：分布直方图或箱线图 + 中位数/四分位解读 + 离群点说明
- **呈现形态**：单独一屏或与 B12 并排
- **禁忌**：样本量 <30 时不出分布图，统计意义不足

#### B12 关联与相关
- **必需度**：条件
- **触发条件**：存在 ≥2 个数值维度且有效样本 ≥30
- **内容要素**：散点图 / 相关性热力图 / 雷达图 + 相关系数或信息熵说明
- **呈现形态**：与 B10 并排
- **禁忌**：必须声明「相关不等于因果」

#### B13 明细透视表
- **必需度**：条件
- **触发条件**：用户要求看明细，或需要 TopN 清单支撑结论
- **内容要素**：行列维度 + 指标值 + 条件格式（数据条/色阶）
- **呈现形态**：表格，行数 >20 时只出 Top20 + 合计行
- **禁忌**：不得输出原始明细全量（违反数据安全：原始明细不上前端），只出聚合或 TopN

#### B14 预测展望
- **必需度**：条件
- **触发条件**：时间点 ≥8 且用户明确提出预测诉求
- **内容要素**：历史值 + 移动平均 + 预测值 + 置信带
- **呈现形态**：多折线图（实线历史 / 虚线预测 / 半透明置信带）
- **禁忌**：必须先声明预测方法（移动平均/线性趋势）；不得把预测值呈现为确定事实

### 族 D · 结论 CONCLUSION

#### B15 核心发现
- **必需度**：必需
- **触发条件**：无条件
- **内容要素**：≥3 条核心发现，每条 = 结论 + 支撑证据（指标 + 变化幅度）
- **呈现形态**：编号列表，可按级别标注（核心 / 机会 / 风险 / 基础）
- **禁忌**：少于 3 条说明分析不足；不得出现无数据支撑的主观判断

#### B16 风险与机会
- **必需度**：必需
- **触发条件**：无条件（无风险时明写「本期未识别到显著风险」）
- **内容要素**：双列——风险（描述 + 影响面 + 信号指标）× 机会（描述 + 抓取条件）
- **呈现形态**：左右双栏 `prose`
- **禁忌**：不得两项都留空；不得把普通波动包装成风险

#### B17 行动建议
- **必需度**：条件
- **触发条件**：B15/B16 中识别出可行动项
- **内容要素**：每条 = 建议 + 责任方向 + 优先级（高/中/低）+ 预期效果
- **呈现形态**：编号列表，优先级用文字标签而非仅颜色
- **禁忌**：不得给出无责任方向的口号式建议

### 族 E · 说明 META

#### B18 口径与指标定义
- **必需度**：必需
- **触发条件**：无条件
- **内容要素**：每个指标的**计算口径**、数据来源、统计周期、字段含义
- **呈现形态**：两列小字表格
- **禁忌**：不得省略——口径缺失的报表无法被复核，是商务报表的硬伤

#### B19 数据质量说明
- **必需度**：条件
- **触发条件**：数据质量评分 <90，或存在缺失值/异常值/重复行
- **内容要素**：完整度 · 缺失字段与缺失率 · 异常值处理方式 · 去重规则
- **呈现形态**：要点列表 + 质量分
- **禁忌**：不得隐瞒缺失；不得声称「已清洗」而不说清洗规则

#### B20 分析方法论
- **必需度**：条件
- **触发条件**：报告使用了高级分析（帕累托 / 雷达 / 洛伦兹 / 箱线 / 热力 / 预测）
- **内容要素**：所用方法清单 + 每种方法的用途一句话 + 适用性说明
- **呈现形态**：编号列表
- **禁忌**：未使用的分析方法不得列入

### 族 F · 收尾 CLOSE

#### B21 附录与术语
- **必需度**：可选
- **触发条件**：报告含专业术语或需附完整数据表
- **内容要素**：术语表（术语 + 定义）· 可选完整聚合表
- **呈现形态**：两列表格
- **禁忌**：附录不得成为原始明细的藏身处

#### B22 结尾与下一步
- **必需度**：必需
- **触发条件**：无条件
- **内容要素**：一句话复述本期核心结论 + 下一步动作或下次回顾节点 + 数据更新日期
- **呈现形态**：整屏，呼应封面
- **禁忌**：不得只写「谢谢观看」

## 三、板块选型规则（供「汇报内容选型」阶段执行）

1. **必先纳必需板块**：B01 / B02 / B04 / B15 / B16 / B18 / B22 共 7 个，无条件纳入。
2. **再按触发条件纳分析板块**：逐条核对 B05–B14 的触发条件，**满足即纳入，不满足不纳入**，不得为了「看起来丰富」而纳入无数据支撑的板块。
3. **再按用户诉求纳可选板块**：B03 / B06 / B21 仅当用户明确要求或条件成立时纳入。
4. **板块数控制**：投屏类报表 ≤10 个板块；阅读类长报告 ≤18 个板块。超出时按「核心板块保底 → 分析族至少留 2 个 → 族序（分析 → 指标 → 结论 → 开场 → 说明 → 收尾）」裁剪，并在 `_cs-content.md` 记录被裁板块与原因。
5. **每板块必须绑定板块 id 与 section type**，供生成阶段直接装配。
6. **不得自创板块**：确需新增时，先在 `_cs-content.md` 用 `custom` 说明结构，并在最终报告的风险项中登记「使用了库外板块」。
