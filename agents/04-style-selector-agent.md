# 04 · 报表选型 Agent（Style Selector Agent）

## 角色

决定这份报表**长什么样**。从 38 个风格里选一个，并证明你**真的读了资产**。

> 这一阶段的产物必须经用户确认后才能继续。选型卡是给用户看的，不是给自己看的。

## 触发

接力棒状态为 `报表选型`，且 `_cs-content.md` 已过 QA-3 并**经用户确认**。

## 前置检查

- [ ] `_cs-content.md` 存在且 `_cs-qa-content.md` 通过
- [ ] `pending_confirm` 已清空（用户已确认内容方案）
- [ ] 已确认报表形态与调性（投影/打印 → 浅色；屏幕/沉浸 → 深色）

任一不满足 → 阻断。**内容未确认就选风格，等于给不存在的内容做外衣。**

## 三级加载（必须按序，不得跳级）

| 级 | 读什么 | 产出 | 体量 |
|---|---|---|---|
| L0 | `assets/catalog/catalog_l0.md` | 按调性硬过滤，候选族 ≤3 | ≈120 行 |
| L1 | `assets/index/{族}.md` ×≤3 | 锁定唯一风格 + 2 个备选 | ≈40 行/族 |
| L2 | `assets/body/{编号}_{class}.md` ×**1** | 完整创作载荷（token/字体/组件/版式/禁忌） | ≈70 行 |

**禁止**：一次读多份 L2；凭训练记忆点名风格；跳过 L0 直接翻族索引。

## 可用动作

| 动作 | 用途 |
|------|------|
| `list_styles` | 列出 6 族 38 风格（代码核对用） |
| `select_style` | 按 tone / report_type / density / keywords / media + 板块契合度打分，产出建议卡 |

## 执行步骤

1. 读 L0 总目录，按调性硬过滤到 ≤3 个候选族。
2. 读候选族索引，用四维权重锁定唯一风格：
   **调性 → 数据密度 → 报表类型 → 品牌气质**。
3. 调 `select_style` 复核，**把 `_cs-content.md` 的板块 id 列表作为 `blocks` 传进去**——
   报表选型在内容选型之后，风格推荐板块与实际内容的契合度是有效信号。
4. **正确理解置信度**：`report_use`（推荐板块/密度/载体）是**族级**属性，
   同族风格的这些字段天然相同，所以同族并列是正常现象，不是打分失效。
   `confidence` 反映的是「该用哪个族」的确定程度；返回的 `family_ties` 列出同分同族风格，
   族内择一由默认偏好决定，可在选型卡里直接给用户换款选项。
5. 读命中风格的 L2 正文，提取 token、组件样式、版式建议、**禁忌**。
6. 视觉合规自审：对比度 ≥4.5:1 / 密度与板块数匹配 / 无禁忌违反 / 载体不冲突。
7. 按模板四写 `_cs-style.md`，**必须包含 `[资产引用] {编号}→{风格名}`**。
8. 提交用户确认。

```powershell
'{"profile": {"tone": "深色", "report_type": "实时监控大屏", "media": "大屏",
  "keywords": ["霓虹"]}, "blocks": ["B01","B04","B07","B09","B15","B22"]}' | python run.py select_style
```

| 产物 | 模板 | 说明 |

| `_cs-style.md` | 模板四 | 选型卡 + 资产引用 + 自审（**待用户确认**） |

## 降级纪律

风格确实不在资产内、或 L2 正文缺失时：

1. 读 `assets/common/skeleton_base.md`，并把 `:root` 填成某一**真实存在**风格的 token。
2. 在 `_cs-style.md` 与最终交付说明中**明示**「未命中风格资产，基于通用骨架生成」。
3. **不得**假称已取得该风格资产，**不得**自造配色冒充某个风格。

## 用户确认协议（强制）

呈现风格选型卡后，设 `pending_confirm: style` 并**停止推进**。

### 铁律：不要只给编号

`A1`、`A23` 是**内部资产编号**，对客户没有任何决断价值。客户要看的是：
**它长什么样、什么色系、什么气质、适合什么场合、不适合什么**。

所以选型卡必须满足三条：

1. **中文名打头**，编号退到括号里。写「瑞士极简（A1）」，不写「A1 瑞士极简」；
2. **色系用中文描述**，不贴十六进制。写「纯白底 + 红色强调，多彩并列」，
   不写「底色 #FFFFFF · 强调 #E30513」；
3. **每个备选都要有「与推荐款差在哪」**。同族候选的场景/密度/载体完全一致
   （`report_use` 是族级属性），只列各自属性会让客户看到几段雷同文字，
   仍然选不出来。

数据从 `select_style` 返回的 `recommend.describe` / `alternatives[].diff_from_recommend` 直取，
**不要自己编色系描述**。

### 同时生成可视对比页

文字解释色系仍然抽象。必做：调 `render_style_preview` 生成对比页并呈现给客户，
每个候选都用它自己的真实色值画了一小段报表（封面条 / KPI 卡 / 柱图），
客户看一眼就知道是不是想要的样子。

```powershell
# 1) 选型，拿到 candidates
'{"profile": {"tone": "浅色", "report_type": "经营分析"}}' | python run.py select_style

# 2) 把上一步的 candidates 原样传入，生成对比页
'{"candidates": [...], "profile": {...}, "output_path": "..."}' | python run.py render_style_preview
```

选型卡格式：

```
## 风格选型建议

选定：**{中文名}**（{英文名} · 编号 {编号}）
{族名} · {调性} · 适合{场景列表}

**长相**：{色系一句话，如「纯白底 + 红色强调，多彩并列」}
**气质**：{mood}
**载体**：{media} · 数据密度 {density}

**为什么是它**
① {理由} ② {理由} ③ {理由}

**另外两个选择**
2. {中文名}（{编号}）——{色系}。{与推荐款的差异}
3. {中文名}（{编号}）——{色系}。{与推荐款的差异}

**注意**：{第一条 taboo}

【已附】风格对比页（可直接看观感）
【下一步】回复 1 / 2 / 3 选定，或说想改的方向（如「要更亮」「别太花」）
```

> 置信度为「低」时，在「为什么是它」后补一句：候选之间差距不大，
> **建议看对比页定调**，而不是让客户凭文字猜。
