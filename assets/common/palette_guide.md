# 配色与无障碍指南

> 依据 `assets/style-system.json` 的 token 约定。风格切换只改 `:root` 变量，不动结构。

## 一、颜色变量约定

所有风格统一收敛到 7 个 CSS 变量：

| 变量 | 含义 | 用途 |
|------|------|------|
| `--bg` | 页面背景 | 报表底色 |
| `--card` | 卡片背景 | KPI 卡 / 图表卡 / 表格容器 |
| `--ink` | 主文字色 | 标题 / 正文 / 数值 |
| `--mu` | 次要文字色 | 标签 / 说明 / 脚注 |
| `--ac` | 强调色 | 主系列 / 重点 / 按钮 / 数据条 |
| `--line` | 分割线 | 边框 / 分隔线 / 网格线 |
| `--font` | 字体族 | 全局字体 |

**取值来源**：`style-system.json` 的 `styles[].tokens`。**不得自行编造色值**——若所需风格不在资产内，按 `assets/common/skeleton_base.md` 兜底并明示。

## 二、对比度要求（WCAG AA）

| 场景 | 要求 |
|------|------|
| 正文文字（`--ink` on `--bg`） | ≥ 4.5:1 |
| 大字标题（≥24px 或 ≥18.66px 加粗） | ≥ 3:1 |
| 次要文字（`--mu` on `--bg`） | ≥ 3:1，且不得低于 3:1 |
| 强调色作文字底色上的文字 | 与 `--ac` 对比度 ≥ 4.5:1，否则改用 `--ink` 或加深强调色 |
| 图表数据块之间的辨识 | 相邻系列色不得仅靠明度区分，须有色相差 |

> 全部 38 风格已由 `tools/check_style_assets.py` 自动校验 `--ink`/`--bg` 对比度，当前 0 告警。

## 三、图表序列色规则

1. **顺序固定**：每族有一套 6 色序列（见 `style-system.json` 的 `families[].series`），生成时**首位由该风格的 `--ac` 覆盖**，其余按序取用。不得跳号。
2. **不得扩色**：类别数 > 6 时改用「排序 + 汇总 Others」，不得自造第 7 色。
3. **同屏一致**：同一报表内所有图表共用同一序列色，保证「同色 = 同维度」。
4. **红涨绿跌（中国习惯）**：涉及增减的图表，正向用红系、负向用绿系，与 `--ac` 无关。此规则优先于序列色。
5. **黑白保底**：所有靠颜色区分的语义（正负、达标/未达标、优先级）必须同时用形状或文字标注，保证灰度打印可读。

## 四、调性对照

| 调性 | 背景倾向 | 文字倾向 | 强调色倾向 |
|------|---------|---------|-----------|
| 浅色（投影 / 打印） | `#F5F5F7` ~ `#FFFFFF` | `#111` ~ `#1D1D1F` | 中高饱和，避免过亮 |
| 深色（屏幕 / 沉浸） | `#0A0A12` ~ `#1E1E2E` | `#F5F5FA` ~ `#FFFFFF` | 高亮霓虹，避免过暗 |
| 混合 | 按所选风格的实际 `--bg` 判定 | 同左 | 同左 |

**判定方式**：以 `--bg` 的相对亮度 < 0.35 判为深色，不依据风格的族归属。

## 五、字体栈约定

| 用途 | 字体栈 |
|------|--------|
| 中文无衬线（默认） | `'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', system-ui, sans-serif` |
| 中文衬线（纸感 / 编辑类） | `'Noto Serif SC', 'Songti SC', 'SimSun', serif` |
| 等宽（终端 / 代码类） | `'Sarasa Gothic SC', 'JetBrains Mono', 'Courier New', monospace` |
| 数字（KPI 数值） | 优先使用字体自身的 tabular-nums；无则用等宽数字保证对齐 |

**无联网兜底**：不加载外部字体（含 Google Fonts），一律使用系统字体栈，保证离线可用。

## 六、密度与留白

| 数据密度 | 区块间距 | 卡片内边距 | 说明 |
|---------|---------|-----------|------|
| 高 | 16px | 16–20px | 明细多、指标密（纸感编辑 / 商务通稿） |
| 中 | 20px | 20–24px | 常规报表 |
| 低 | 28–32px | 24–32px | 讲观点、重冲击（表达张力 / 部分大屏） |

密度取自所选风格的 `report_use.density`，不得跨密度套用。
