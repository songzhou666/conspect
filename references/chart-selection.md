# 图表选型指南

> 本文档定义 conspect Skill 的图表选型规则和调用方式。

---

## 一、执行者：AI Agent

**职责**：根据数据特征和业务场景选择图表类型

**输入**：
- 数据特征（CLI 提取）
- 业务场景（用户描述）

**输出**：
- 图表类型
- 选择理由
- 图表配置

---

## 二、调用方式

```bash
# 1. CLI 提取数据特征
python run.py extract_features '{"data": {...}}'

# 2. AI Agent 图表选型决策
python run.py ai_decide_chart '{"features": {...}, "business_context": "<根据数据源自动识别的业务场景>"}'
```

---

## 三、图表选型规则（AI 参考）

| 数据特征 | 推荐图表 | 说明 |
|---------|---------|------|
| 时间序列 + 数值 | 折线图 | 展示时间趋势 |
| 时间序列 + 数值（数据点 > 50） | 面积图 | 数据点较多，面积图更清晰 |
| 分类 + 数值（分类 ≤ 5） | 饼图 | 展示占比 |
| 分类 + 数值（5 < 分类 ≤ 10） | 柱状图 | 分类对比 |
| 分类 + 数值（分类 > 10） | 横向条形图 | 分类较多，横向更清晰 |
| 数值分布 | 直方图 | 展示分布 |
| 两个数值关系 | 散点图 | 展示相关性 |

**注意**：图表选型规则仅供参考，AI Agent 应根据具体业务场景灵活选择。
