# 使用示例

## 一、典型开场白

```
帮我分析这份业务数据，出一份周报看板
```
→ 走完整五阶段，报表形态按投屏（≤10 板块）

```
对比一下这两个月的经营数据，做一份投屏用的报表
```
→ 上传两份数据源，自动做同比分析

```
把这三个部门的业绩数据合在一起做个排名看板，风格要深色科技感
```
→ 多源合并；「深色」「科技」会直接命中数据大屏族，选型阶段少一轮过滤

```
这份数据出一份给管理层看的年度报告，要能打印
```
→ 报表形态按阅读（≤18 板块），调性过滤到浅色族（商务通稿 / 纸感编辑）

## 二、Conspect 自动执行的步骤

以「帮我分析这份数据，出一份周报看板」为例：

| 步骤 | 阶段 | 做了什么 | 结果 |
|------|------|---------|------|
| 1 | 读取数据 | 读取 Excel，枚举全部 Sheet，识别「日期 / 产品线 / 区域」为维度、「销售额 / 数量」为指标，算质量分 | `_cs-datamap.md` |
| 2 | 分析数据 | 按产品线分组汇总销售额、按区域统计排名、算环比，生成洞察与建议 | `_cs-analysis.md`、`_cs-insights.json` |
| 3 | **汇报内容选型** | 按触发条件组装板块：必需 7 个 + 趋势（时间 12 个时点）+ 结构（区域 5 类）+ 排名（产品线 7 类）；剔除归因（无贡献结构） | `_cs-content.md` → **等你确认** |
| 4 | **报表选型** | L0 按浅色过滤到商务通稿族 → L1 锁定 A12 扁平无影（高密度、投影/打印） | `_cs-style.md` → **等你确认** |
| 5 | 生成报表 | 按 10 个板块装配 + 注入 A12 token 渲染；出 HTML/MD/中文副本；内核验数据一致性 | `_cs-dashboard.html`、`_cs-report.md` |

## 三、两个确认点长什么样

### 内容确认

```
## 汇报内容方案（10 个板块 · 投屏）
【必需】B01 封面 · B02 执行摘要 · B04 KPI 指标墙 · B15 核心发现
        B16 风险与机会 · B18 口径与指标定义 · B22 结尾与下一步
【数据驱动】B07 趋势分析（时间维度 12 个时点）
            B08 结构构成（区域 5 类）
            B09 对比排名（产品线 7 类）
【已剔除】B10 归因（无贡献结构）· B11 分布（非重复值仅 12）
          B13 明细（未要求）· B14 预测（时间点 <8）
【下一步】1 按此生成  2 增删板块  3 重新选型
```

### 风格确认

```
## 风格选型建议卡
【族】商务通稿 BIZ（浅色 · 正式汇报/年度报告/经营分析/打印分发）
【推荐】A12 扁平无影 · FLAT DESIGN
【配色】底色 #FFFFFF · 文字 #111111 · 强调 #3497DB · 卡片 #FFFFFF
【理由】① 调性=浅色 完全命中 ② 报表类型命中「经营分析」
        ③ 数据密度=高，契合 10 板块的密排 ④ 载体含投影+打印，符合周报分发
【置信度】高
【备选】a) A1 瑞士极简  b) A17 包容无界
【下一步】1 就用推荐  2 换风格（给编号）  3 换族重选
```

## 四、常见调整

| 你想做的事 | 怎么说 | 走哪条路 |
|-----------|--------|---------|
| 少几个板块 | 「去掉风险与机会，把明细表加上」 | 从「汇报内容选型」重入 |
| 换风格 | 「换成赛博朋克那款」 | 从「报表选型」重入，指定 `A23` |
| 换个族 | 「太素了，换深色大屏」 | 从「报表选型」重入，重走 L0 |
| 加数据重跑 | 「又补了 9 月的数据，重新出一份」 | 从「读取数据」重入，清空确认记录 |
| 只改一个数字 | 不建议手改产物 | 回分析数据阶段重算，保证全文一致 |

## 五、最终产出

一份可在浏览器打开的 `_cs-dashboard.html`，包含：

- 页头：报表标题 + 一句话结论 + 数据范围与生成日期
- 执行摘要：3–5 条核心结论
- KPI 指标墙：总销售额、总数量、环比涨跌幅
- 分析板块：趋势折线图、区域构成图、产品线排名图，每图下方带数据解读
- 核心发现 + 风险与机会
- 口径与指标定义 + 结尾下一步

外加 `_cs-report.md`（分析报告）、`分析报告.md`（中文副本）、`_cs-index.json`（关联索引）。
