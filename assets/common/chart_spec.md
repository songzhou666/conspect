# 图表规格

> 图表选型规则的可读版本。权威实现：`conspect_tools/ai_agent.py` 的 `_decide_chart_impl()`
> 与 `conspect_tools/config.py` 的图表规则表。两者不一致时以**代码为准**。

---

## 一、选型执行者

图表选型由 **AI Agent 决策**，CLI 提供数据特征与规则表支持。

| 项 | 内容 |
|----|------|
| 输入 | 数据特征（`extract_features` 提取）+ 业务场景（从数据源与用户需求识别） |
| 输出 | 图表类型、选择理由、ECharts 配置参数 |
| 兜底 | `ai_decide_chart` 异常时降级返回柱状图，不阻断流程 |

```powershell
cd {CLI_DIR}
'{"data": {...}}' | python run.py extract_features
'{"features": {...}, "business_context": "<业务场景>"}' | python run.py ai_decide_chart
```

## 二、基础选型规则（代码直接判定，优先级从高到低）

| 数据特征 | 图表类型 |
|----------|---------|
| 时间维度 + 数值维度，数据点 > 50 | `area` 面积图 |
| 时间维度 + 数值维度，数据点 ≤ 50 | `line` 折线图 |
| 分类维度 + 数值维度，分类数 > 10 | `horizontal_bar` 横向条形图 |
| 分类维度 + 数值维度，5 < 分类数 ≤ 10 | `bar` 柱状图 |
| 分类维度 + 数值维度，分类数 ≤ 5 | `pie` 饼图 |
| 仅数值维度 | `histogram` 直方图 |
| 无可用特征 | `bar` 柱状图（兜底） |

## 四、选型优先级

```
数据特征匹配度 > 图表可读性 > 视觉多样性 > 实现复杂度
```

- 同一报表内图表类型**由数据特征驱动**，不设人为数量上限。
- 高级分析图表（帕累托 / 雷达 / 洛伦兹 / 箱线 / 热力 / 预测）**仅在对应板块被纳入时出现**，
  板块触发规则见 `assets/common/block_library.md`。
- **图表配色序列**取自 `style-system.json` 的族级 `series`，规则见 `assets/common/palette_guide.md` 第三节。

## 五、图表类型清单（引擎能力边界）

`conspect_tools/render_engine.py` 的 `ChartBuilder` 已实现 14 种：

`line` · `bar` · `horizontal_bar` · `stacked_bar` · `pie` · `funnel` · `radar` ·
`scatter` · `heatmap` · `sankey` · `gauge` · `treemap` · `word_cloud` · `area`

超出此清单的图表类型不受支持；确需时在报告中降级为等效类型并说明。
