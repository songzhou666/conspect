# conspect 产物模板（v4.0）

> 模板编号与 [artifact-manifest.yaml](artifact-manifest.yaml) 的 `template` 字段一一对应。
> 产物清单的**权威定义**在 manifest，本文件只提供模板正文。

| 编号 | 模板 | 用于产物 |
|------|------|---------|
| 一 | 数据源清单 | `_cs-datamap.md` |
| 二 | 数据分析结果 | `_cs-analysis.md` |
| 三 | 板块组合方案 | `_cs-content.md` |
| 四 | 风格选型卡 | `_cs-style.md` |
| 五 | 渲染摘要 | `_cs-render.md` |
| 六 | 分析报告 | `_cs-report.md` |
| 七 | 内核验报告 | `_cs-verify.md` |
| 八 | 质量审核报告 | `_cs-qa-{read,analyze,content,style,render}.md` |
| 九 | 最终汇总报告 | `_cs-final-report.md` |

---

## 一、数据源清单模板

```markdown

| # | 文件名 | 大小 | Sheet 数 | 质量分 |

|----|-----|------|

{数据能支撑什么分析、不能支撑什么分析，逐条列出}
```
